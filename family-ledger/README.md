# 家有账 · 跨设备同步版

访问 https://sshakiraa.github.io/family-ledger/ ，首次注册账本邮箱账号，验证邮件后登录。电脑、手机使用同一个账本账号。

- 前台登录使用 Supabase Auth，数据库 `public.family_ledger` 启用 RLS，每人只能访问自己的账本。
- 每次修改先写当前浏览器按账号隔离的缓存，再通过 `save_family_ledger` RPC 按 revision 比较并更新。
- 页面在前台每 12 秒检查云端，并在回到页面或网络恢复时同步。两台设备同时编辑时不自动合并：保留本机待同步数据，提示冲突，导出本机备份后可加载云端再核对补录。
- 关闭网页前确认顶部显示「已同步至云端」。断网暂存不代表已经上传；重新打开页面需要联网登录／加载。
- 离线版的原数据不会自动上传。在离线版点击「完整备份」，然后登录此版，点击「恢复备份」，确认替换当前云端账本。请先备份两边数据。
- 完整 JSON 备份含全部记录和预算，未加密，请妥善保留。CSV 仅用于查看。
- 页面源码和前端 publishable key 可公开，真实账目只存在用户浏览器和受 RLS 保护的 Supabase 数据库，不提交到代码仓库。
- 官方 supabase-js 客户端固定为 2.57.4，并随站点托管，不依赖运行时 CDN。`schema.sql` 是已应用的初始结构。测试：`node sync.test.cjs`。
- 一个账本最大约 5 MB。不同邮箱账号各有独立账本；当前版本不支持不同账号的家庭成员共享。
